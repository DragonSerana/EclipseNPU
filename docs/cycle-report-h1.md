# Cycle 报告 H1：128×128×128 matmul（K 分块 8×16）

配置：MAC 256/周期；DMA 32B/周期 + 16 固定开销；DDR 16B 突发对齐。
数据：随机 fp16，seed 0。指令流：8 轮 [DMA A-tile + DMA B-tile + SYNC + MATMUL] + SYNC + DMA_STORE。

## 逐指令明细

| 指令 | 次数 | 单次 | 小计 | 说明 |
|---|---|---|---|---|
| DMA_LOAD A-tile | 8 | 144 | 1152 | 128×16，行 32B 对齐 = 2 突发，共 256 突发 → 128+16 |
| DMA_LOAD B-tile | 8 | 144 | 1152 | 16×128，行 256B = 16 突发 × 16 行 = 256 突发 |
| MATMUL | 8 | 1024 | 8192 | ceil(128×128/256) × K16 = 64×16 |
| SYNC | 17 | 0 | 0 | 串行模型无在飞指令 |
| DMA_STORE | 1 | 1040 | 1040 | 128×128 整块 2048 突发 → 1024+16 |
| **总计** | | | **11536** | |

## 结论

- K 分块不损失算力：8 条 MATMUL 总周期 8192，与不分块版相同；不分块版总周期 11312，分块版 11536，多出的 224 cycles 全来自 tile 搬运（16 次小 DMA 共 2304 vs 整块搬 2×1040=2080）。
- 优化点（H2 双缓冲实验的素材）：B-tile 每轮重搬（8×144=1152），B 整块一次搬入只要 1040，省 112 cycles；A-tile 行宽 32B 恰好对齐无突发损失，换成非对齐 tile 会看到突发惩罚。
- 数值：分块 8 实测误差 8.4e-4 < 1e-2，误差模型见 docs/spec/accuracy.md。
