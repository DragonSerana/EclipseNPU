## LLM
token
  通过BPE 算法对中文拆字或者合并，一般一个字就是一个token，但是常见词也可能两个字作为一个token,而罕见字需要多个token形容一个字。

llm的shape
  [Batch, sequence, hidden_size]
  Batch 几句话
  sequence 几个token
  hidden_size 描述一个token抽象的维度

hidden_size
  比如hidden_size是896,那就说用896个数字描述了这个token，假如hidden_size是3，就是立体坐标系中的一个点，然后，描述这个token的就是  (0,0,0) 到 (x,y,z)这个点的向量 。那方向越接近，说明这两个词语义上越像，向量越短，说明这个词信息密度越低。词向量的方向，才有实际的意义，单独分开横纵高的坐标没有任何意义。
  BSH和NCHW一样 ，都是输入，只是H的对应表，即每个字对应的向量，在训练阶段会改变。
    罕见词/专有名词（如“薛定谔的猫”）往往向量特别长，因为它携带的信息很独特，离原点很远。
    常用虚词/停用词（比如“的”、“是”、“了”）往往向量特别比短，因为它们依赖上下文，本身没啥具体语义，缩在原点附近。

  wordvec
    假设我们用 3 个数字（简单版）来描述这两个词：
        男人 = [5, 1, 0]
        女人 = [2, 8, 0]
        国王 = [9, 3, 0]

    我们先算“性别差异向量（箭头）”：
    用 女人 - 男人 = [2-5, 8-1, 0-0] = [-3, 7, 0]。
    这个 (-3, 7) 的箭头，在空间里代表的就是从“男”指向“女”的“性别方向轴”。

    现在代入公式：
    国王 - 男人 = [9-5, 3-1, 0-0] = [4, 2, 0]（这表示“国王”剥离了“男性”身份后剩下的“王权”内核）。
    [4, 2, 0] + [-3, 7, 0] = [1, 9, 0]。

    你会发现，[1, 9, 0] 这个坐标，恰好就是“女王”这个词在空间里落脚的位置！

自注意力机制（Self-Attention Mechanism）
  词向量的QKV，所以Q就是这个token需要什么其他类型的词，才能表达完整的意思。K就是这个token能提供什么意思，什么类型的词。而V就是这个词具体的意思。我非常快乐这句话里面，“非常”这个token的Q就是说 ，非常这个词是修饰用的，所以必须要修饰某种东西，而且经常用来修饰情绪。而“快乐”这个词的K就是，一种情绪。所以非常快乐就匹配上了，而且拿到"快乐"这个词的V,表示舒畅，高兴

  词向量的QKV，通过输入x(hidden_size维的token)
  注意，词向量的维度，和矩阵乘法的tensor维度不一样，词向量的维度，其实最后是以hidden_size个数字的坐标，以一维数据放在tensor中的。
    x 是一个 896 维的行向量 [1, 896]，W_q 是一个 [896, 896] 的矩阵。
    矩阵乘法 x*W_q, [1, 896] × [896, 896]，结果是 [1, 896]。shape没变，但是意思已经变成了这个token的query
    原始 X带着这个 token 的 query/key/value 三个信息，通过乘以 q_w/k_w/v_w,就加权求出来了这个 token 在 QKV 方向的含义了
    q_w的 896*896个数字 完全 就是  随机 的，通过喂给 矩阵乘法 巨量的文本，然后虽然 不知道 q_w是啥 样的 ，但是 知道 目标 结果，也就是 人类给出的文本 ，画出目标函数。如果 计算之后 发现 这个 函数 距离 目标 很远 ，那就调整这个q_w矩阵的数字，直到 q_w能够 完整的 找到 词向量 中query 的 含义。但是其实人类根本完全理解不了这个权重矩阵 。

点积
  两个向量，对应位置相乘，然后全部加起来。
  如果放在 坐标系中 ，A(x1,y1) B(x2,y2) ，那 A到 B的长度的平方 就是 (x1-x2)^2+(y1-y2)^2
  与向量定义相同，向量A-B就是(x1-x2,y1-y2)。向量A-B和自己的点积就是(x1-x2)^2+(y1-y2)^2，也就是坐标系中实际计算的值。所以，向量的长度平方就是自己和自己的点积
  C^2 = (A-B)*(A-B) = |A|^2 + |B|^2 - 2(A·B)

余弦定理
  对于 任意夹角a，且 知道 两个 向量的 模长，带入 余弦公式 
  C^2=A^2+B^2-2ABcos(a)

  根据余弦定理和点积公式
  |A|^2 + |B|^2 - 2|A||B|cosθ = |A|^2 + |B|^2 - 2(A·B)
  化简得A·B = |A||B|cosθ

  有因为计算attention之前，AB都被拉到sqrt(896)的长度，所以点积越大，cosθ越大，两个向量的夹角越小

前向传播：正向跑一边模型，得到下一个token的概率 
损失函数：根据前向传播计算的正确的那个词 概率，给他打分。给的正确词的概率越高，Loss越小
反向传播：从结果反着走一遍模型，看看是那个参数导致的Loss比较大
梯度：Loss函数对这个参数的导数。如果>0,那参数变小Loss变小，如果>0,那就参数变大Loss变小

单头（Single-Head）和多头（Multi-Head）：
  把 896 维切成 hh 份（比如 8 份，每份 112 维），每一份独立跑一遍 Attention

旋转矩阵
  矩阵是一组有序的向量
  行向量、列向量长度都是 1，列向量两两垂直，并且行列式等于 +1

KV cahce
  就是输入通过 attention算出来的K/V这两个 向量缓存起来

## LLM相关算子
1. RMSNorm Root Mean Square Normalization（均方根归一化）
  就是 把 输入的 每个 token词 向量 压到 sqrt(hidden_size)为半径的多维球面。
  RMS(x) = sqrt( (1/n) * (x_1^2 + x_2^2 + ... + x_n^2) )
  RMSNorm(x) = [ x / (RMS(x) + eps) ] * gamma
  eps是极小值，防止除0错误

  比如 一个 二维坐标，(3,4)，这个其实就是输入x.模长 就是 5,那归一化之后 的 坐标 就是 [3/5,4/5]，模长 就是 sqrt(1),也就是 1.所以 归一化 就是 把 各种 长度的 词向量，通过坐标/模长的方法，拉到半径 是1(这里是sqrt(896))  的 多维球面。比如 第二个 token进来，坐标 是(300,400)，归一化之后的坐标也变成了[3/5,4/5]。

  x 是向量，RMS(x) 是标量，向量除以标量，就是向量的每一个元素分别除以这个标量。

2. RoPE（旋转位置编码）
  假设一个点xy，旋转一定角度得到x'y'.根据三角函数变换
  x=r*cosa -> x' = xcosθ−ysinθ
  y=r*sina -> y' = xsinθ+ycosθ
  
  写成矩阵,R(θ),旋转矩阵
  [x′,y′​]=[[cosθ,-sinθ][​sinθ,cosθ​]]*[x,y​]

  qm'=qm@R(θm),qn'=qn@R(θn)
  qm'^T@kn'=qm^T@R(θ(n-m))@kn，这个公式说明，两个向量旋转角度后的点积，只和两个向量旋转的角度差有关，角度差正比与位置差(n-m)
  然后把896维度的向量，拆成896/2个二维平面，每个 二维 旋转 角度 不一样，所以能感受的距离就不一样
  每对旋转角度的步幅θi​=10000^−2i/896，对于第 i 对维度，Q 和 K 用的是同一个 θi​，但 Q 转的是 mθi​，K 转的是 nθi​。两者的绝对旋转角度不同，但相减后变成 (n−m)θi​，所以点积结果只和n-m相关
  这些二维平面的旋转会改变语义，但是因为步幅已知，所以在训练权重的时候，已经将改变的语义融合进了权重 

3. Attention（自注意力，包含 Q@K^T + Softmax）
  attention的 前半部分 ，就是通过 矩阵乘权重  拆出 词向量的 QKV分量 ，然后一个 batch里面，所有 token的 shape就是 [seq,896],Q@K^T，也就是 [seq,896]@[896,seq],得到[seq,seq]这么大 矩阵 ，根据 余弦定理和代数 公式 ，A·B = |A||B|cosθ，|A||B|已经被RMSNorm限制相同，所以A@B正比于 cosθ，因此，A和B的 点积越大，就是 方向越一致. Q @ K^T 那就是Q与K的转置，也就是Q的行与K^T的列越相似，也就是Q的行与K的行越相似

  除以以 根号 dk,是为了 让 方差 是一 ，在经过 softmax，把之前 Q@K^T算出来的值变成一行加起来等于 1 的概率分布。最后再根据 这个 概率 *V张量([seq,seq]@[seq,896])，这样 就得到一个 融合的 语义，权重 根据 token与 token直接的QK关系 。shape是[seq,896],每行也就代表融合后词向量，融合了这个词关心权重的新词向量。这个关心程度，就是attention，也是attention命名的由来。

4. SwiGLU（前馈门控）
  输入 X: [seq, 896]
  分支 1（门控）：
  G = Swish(X @ W_gate)
    X @ W_gate: [seq, 896] @ [896, 3584] = [seq, 3584]
    Swish 激活: [seq, 3584]
  分支 2（内容）：
  U = X @ W_up
    X @ W_up: [seq, 896] @ [896, 3584] = [seq, 3584]
  门控相乘：
  H = G ⊙ U (Gate/Up/Hidden隐藏层)
    [seq, 3584] ⊙ [seq, 3584] = [seq, 3584]
  降维：
  Output = H @ W_down
    [seq, 3584] @ [3584, 896] = [seq, 896]

  Wq​,Wk​,Wv​：存储“怎么提取 Query/Key/Value”。
  Wgate​：存储“什么信息该通过、什么该抑制”。
  Wup​：存储“怎么把信息升维展开”。
  Wdown​：存储“怎么把高维信息压缩回精华”。

5. Softmax（注意力的归一化，虽然它寄生在 Attention 里，但独立驱动了 EXP/SUM 指令）
  把分数转换成和为1的概率分布
  softmax(z_i) = e^x/(e^x_1+...+e^x_i)

6. LM Head（Language Model Head） → 驱动了 REDUCE 的 ARGMAX 指令。
  从attention算出的词向量，转换为token，是embeding的反向
  LM 矩阵和 Embedding 矩阵互为转置，是词到词向量的相互转换

  logits=h@Wlm，通过attention计算出的词向量映射回token,logits就是对应token的原始分数
  logits‘=logits/T,Temperature 缩放，T越大分布越随机，T越小，logits‘越大，最后做Softmax计算出来的概率越向大的倾斜
  Softmax 计算概率分布 
  Top-k/Top-p过滤，Top-k表示取概率最大的k个，Top-p是概率累加到p的，然后重新归一化，px/p1+p2+...+pn
  采样得到最后的值，如果是Greedy,那就直接argmax


7. 多头注意力（Multi-Head）
  就是输入tokne是 3,896，让他 通过 896,112的 权重 矩阵，得到 3,112的QKV分量。然后 分别 做 attention,得到 [3,112],最后 concat一把 办成 3,896,最后 乘以 w_o 896,896的 
  其实 权重 和 单个896,896描述 的 信息 一样，但是 这样不分头，信息 更 纠缠，最后softmax算出来的东西很模糊。如果拆成 8个 attention,得到 8个 softmax矩阵，每个 提供 一部分 信息，最后 在 引入一个 新的 w_o的 矩阵 ，让训练的时候理解 下文更清晰 。只有 一个 attention+softmax要关注太多词性，注意力涣散

  实际Owen是GQA,也就14 个 Q 头、2 个 KV 头、head_dim = 64。每7个Q头，共用1组KV头
